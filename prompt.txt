PROMPTS SENT TO THE AI MODEL (google/flan-t5-large)
===================================================

The script triage_with_ai.py builds these two questions for every ticket and
feeds them to the local AI model. The model reads the ticket and answers.

1) CATEGORY PROMPT
------------------
Classify this customer support ticket into exactly one category from this list:
Bug, Performance, Billing, Security, Feature Request, Question, Resolved.
A ticket that says a problem is already fixed is Resolved.
Ticket: "<subject>. <body>". Category:

2) PRIORITY PROMPT
------------------
What is the priority of this support ticket? Choose exactly one:
Critical, High, Medium, Low. A security or data leak, or something that stops
customers, is Critical. A fixed issue or a nice-to-have is Low.
Ticket: "<subject>. <body>". Priority:

The model's answer is matched back to the allowed labels. Unlike the keyword
rules, the model understands the sentence, so it handles negation and context.
